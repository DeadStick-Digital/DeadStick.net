3. What the Software does

CarrierPigeonVPN connects this PC to a phone or tablet you own and pair with it, and sends this PC's internet traffic through an encrypted WireGuard tunnel to that device, which then uses its own mobile connection. It is not a commercial VPN service: DeadStick operates no server and no exit node, does not anonymize you on the internet, and does not see the contents, destinations or metadata of your traffic. The installer adds a Windows service that runs as the SYSTEM account, starts with Windows, and changes this PC's network routes, DNS and firewall rules while a connection is up, and puts them back when it ends.
