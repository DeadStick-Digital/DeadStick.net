Why standard script preloaders fail — and how HeadStart fixes them.

Older shell scripts that try to warm `linux page cache` or copy flat 60 MB chunks break on modern 4K HDR10/Dolby Vision Remuxes: MP4 and MKV players immediately seek to the very end of the file (`EOF - 2 MiB`) to read the container index (`moov` atom or MKV `Cues`), stalling on the sleeping hard drive before frame 1 ever renders. And at the 30-second mark, switching filesystems drops frames.

Architecture

Engineered for 100+ TB media servers.

1. Bitrate-Scaled 30s Head + 2 MiB Tail

Instead of a fixed byte size that under-buffers 100 Mbps 4K Remuxes and wastes SSD space on 1080p episodes, HeadStart queries your Plex database in read-only mode (`?mode=ro`) and sizes each `.pchunk` to exactly 30 seconds of video (plus a 15% VBR burst cushion) alongside the last 2 MiB of the file (`moov` / `Cues` index) and external `.srt`/`.ass` subtitles.

2. Zero-Chop 0:30 RAM Ring Splice

Metadata checks (`Stat`, `ReadDir`) and `< 2 MiB` scanner probes are served 100% from NVMe without waking sleeping drives. The moment real playback crosses `2 MiB`, HeadStart wakes only that single target HDD in the background, pre-buffers an `18 MiB` overlap window into RAM, and splices reads across the 30s mark through a single open file descriptor.

3. Automatic Free-Space Watchdog

Using your NVMe pool for SABnzbd, qBittorrent, or Unraid Mover staging? HeadStart monitors your NVMe pool's free space every 10 seconds. If a big download batch pushes free space below your reserve (default 500 GiB), HeadStart automatically evicts lowest-priority TV chunks to hand space back to your downloads immediately — then re-harvests them after Mover runs.

4. Multi-Drive Btrfs & ZFS Pool Safe

Every `.pchunk` file carries a 64-byte `HDSTART1` header with hardware Castagnoli CRC32C checksums for both the head and tail payloads. If an NVMe pool ever suffers a bit flip or truncated write, HeadStart quarantines the chunk and falls back to the array disk mid-stream without interrupting playback.

5. Universal Client Support (Infuse, Apple TV, WebDAV)

Because HeadStart operates at the filesystem layer (read-only Linux FUSE + built-in HTTP Byte-Range & RFC 4918 WebDAV server on `:8999`), every client connected to your server — Plex, Infuse, Jellyfin, Emby, VLC, and IINA — gets instant cold-drive playback automatically.

6. Non-Destructive Pilot Mode & 1-Command Nuke

HeadStart never modifies a single byte of your `/mnt/user` media array. Test it first with a 25-movie side-by-side pilot library, or attach it over `/data` with zero container restart. Stopping or uninstalling HeadStart immediately reveals your untouched underlying array mount.

Downloads & Installation

Install on Unraid, Linux, Windows, or Mac.

Unraid & Linux Servers (FUSE + Container Auto-Attach)

Supports Unraid 6.12+, Ubuntu, Debian, TrueNAS SCALE, and Proxmox. Attaches into `Plex-Media-Server` automatically without restarting the container, and re-attaches automatically after Docker image updates.

  • Unraid Plugin Manifest (headstart.plg) — paste URL in Plugins → Install Plugin
  • Universal Linux/Unraid Installer (install.sh) — auto-detects NVMe pool & Plex DB

Windows & macOS Plex Servers (Built-In WebDAV & Cockpit)

Running Plex on Windows (StableBit DrivePool / Storage Spaces) or macOS with external USB/Thunderbolt DAS bays? HeadStart includes a zero-dependency local WebDAV mount (`/dav/`) and Cockpit UI (`:8999`).

  • Windows x64 / ARM64: Mount http://127.0.0.1:8999/dav/ as a local drive letter or point Infuse/VLC directly to `:8999`.
  • macOS Universal: Press ⌘K in Finder → connect to http://127.0.0.1:8999/dav/.
