Real-World Performance

Why basic cache scripts stall — and how HeadStart solves it.

Simple file-warming scripts stall on modern 4K HDR and Dolby Vision Remuxes because media players check multiple parts of a file before rendering the first frame, forcing your server to wait on a sleeping hard drive anyway. HeadStart preloads everything the player needs to start immediately and bridges the handoff to the spinning drive without a stutter.

How It Works

Engineered for media servers.

1. Smart Bitrate-Aware Preloading

Instead of using a one-size-fits-all cache size that under-buffers high-bitrate 4K Remuxes and wastes SSD space on smaller episodes, HeadStart sizes each preload to the video's true bitrate (from Plex's library database) alongside its subtitles. Without a Plex database it uses a fixed-size preload.

2. Seamless Drive Handoff

HeadStart keeps a complete catalog of every folder on every drive, so library browsing never wakes a sleeping drive and never hides a file that has not been preloaded yet. Only when someone actually presses Play does HeadStart wake that single target drive in the background and hand off the stream once it is up to speed.

3. Automatic Free-Space Watchdog

Using your NVMe drive for downloads or daily cache staging? HeadStart monitors your free space continuously. If a large download batch needs room, HeadStart automatically frees up low-priority preload data so your downloads never slow down, then rebuilds it when space recovers.

4. Polite Background Harvesting

HeadStart prioritizes your newest movies and active TV shows first and harvests across a few drives at a time so the rest of your array stays spun down, quiet, and cool.

5. Works With Your Media Server

Plex is detected automatically. For Jellyfin or Emby, set your server's container name in the plugin settings and HeadStart builds its preload plan from a filesystem scan. Every client of that server — including Infuse — benefits with zero client configuration.

6. Non-Destructive & 1-Click Removable

HeadStart is strictly read-only and never modifies, moves, or renames a single file on your media array. Stopping or removing the plugin — or HeadStart exiting unexpectedly — immediately returns your server to its standard setup without restarting it. Because the overlay is read-only, Plex DVR recordings, “Optimize” versions, and media deletion cannot write into folders HeadStart serves.

Downloads & Installation

Install on Unraid or Linux — stream to every device.

Unraid & Linux Servers

Supports Unraid 6.12+ and Docker-based media servers on Ubuntu and Debian. Attaches to your media server's container without restarting it, re-attaches after container updates and reboots, and detaches automatically if HeadStart ever stops.

  • Unraid Plugin Manifest — paste URL in Plugins → Install Plugin
  • Universal Linux & Unraid Installer — verified download, systemd unit with fail-safe detach, and --uninstall

Windows, macOS & WebDAV Streaming

Connecting from Windows, macOS, iOS, or Apple TV? HeadStart includes built-in read-only WebDAV and HTTP streaming endpoints alongside its live web dashboard. The Windows build runs the preloader with WebDAV/HTTP streaming only — it has no kernel mount, so Windows-hosted Plex, Jellyfin, or Emby libraries do not use it directly.

  • Windows Binary (x64) — preloader with WebDAV & HTTP streaming and dashboard
  • Windows & macOS Clients: Browse or stream over WebDAV and HTTP in Finder, Explorer, VLC, or IINA.
  • Infuse & Direct Players: Point Infuse or any HTTP byte-range player at your server's WebDAV or media stream address.
