Getting started on Unraid & Linux

  1. Unraid WebGUI Plugin: Open your Unraid WebGUI → Plugins → Install Plugin, paste https://www.deadstick.net/headstart/headstart.plg, and click Install.
  2. Or 1-Line Terminal Install: On Unraid run curl -fsSL https://www.deadstick.net/headstart/install.sh | bash over SSH, or on Ubuntu and Debian run curl -fsSL https://www.deadstick.net/headstart/install.sh | sudo bash.
  3. First start: HeadStart builds a one-time catalog of every folder on every drive (this wakes each drive once), then attaches to your media server. Until the catalog is complete your server keeps using its normal media path.
  4. Jellyfin or Emby: edit /boot/config/plugins/headstart/headstart.cfg on Unraid and set PLEX_CONTAINER to your server's container name, then restart HeadStart from the plugin or with /usr/local/emhttp/plugins/headstart/rc.headstart restart.
  5. Open the Live Dashboard: the dashboard listens only on the server itself (127.0.0.1:8999) and requires the access token stored in token inside your HeadStart store. From another computer, use an SSH tunnel: ssh -L 8999:127.0.0.1:8999 root@your-server, then open http://localhost:8999/?token=<token>.

Common questions

Can HeadStart damage or modify my original media files?

No. HeadStart is strictly read-only. Your original media files are never modified, moved, or renamed.

What happens when downloads or Mover need space on my NVMe drive?

HeadStart continuously monitors your NVMe free space. If downloads reduce free space below your configured reserve, HeadStart automatically removes lowest-priority preload data so your downloads have room immediately, then rebuilds the preload cache once space is free again.

How do I completely uninstall HeadStart and revert to normal?

On Unraid, remove the plugin from the Plugins tab. On Linux, run curl -fsSL https://www.deadstick.net/headstart/install.sh | sudo bash -s -- --uninstall. Either way HeadStart detaches without restarting your media server, deletes only its own preload store, and leaves your original media mount untouched.

What happens if HeadStart crashes or stops responding?

A supervisor detaches HeadStart from your media server's container the moment the daemon exits, and stops it after three failed health checks, so your server immediately falls back to its normal media path.

Are there any Plex features that don't work with HeadStart?

HeadStart's view of your library is read-only, so Plex DVR recordings, “Optimize” versions, and “Allow media deletion” cannot write into folders that HeadStart serves.
